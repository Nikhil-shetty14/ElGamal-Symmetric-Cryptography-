05 · Algorithm

Mathematical Explanation

Simple explanations of the ElGamal asymmetric cryptosystem.

1. Key Generation

Choose prime p
Choose generator g
Choose private x

y = gx mod p

Public Key = (p, g, y)
Private Key = x

2. Encryption

Choose random k

c1 = gk mod p
c2 = m × yk mod p

Ciphertext = (c1,c2)

m is the numerical message and k is a fresh ephemeral value.

3. Decryption

s = c1x mod p
s⁻¹ = modular inverse of s
m = c2 × s⁻¹ mod p

The recovered number is converted back to its original character.

Variable Guide

p Prime modulus used for modular arithmetic.
g Generator/base used to create public parameters.
x Private key. It must remain secret.
y Public component calculated as gx mod p.
k Random ephemeral value used for an encryption operation.
m Numerical plaintext value.
c1,c2 The two components of the ElGamal ciphertext.
06 · About

About This Project

ElGamal Cryptography Lab is an educational, client-side demonstration of ElGamal Asymmetric Encryption. It demonstrates public/private keys, modular exponentiation, randomized encryption, modular inverses and plaintext verification. This project is designed for learning and classroom demonstration. The small default parameters are intentionally educational and are not suitable for real-world security.
